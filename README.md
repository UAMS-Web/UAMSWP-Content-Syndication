# UAMSWP Content Syndication

Content Syndication plugin for uams.edu and uamshealth.com.

It adds the `[uamswp_news]` shortcode, which shows posts from another WordPress site's REST API, or from the site it runs on, as headlines, excerpts, cards, full articles or a JSON object.

## Requirements

- WordPress 6.8 or later
- PHP 8.2 or later

## Documentation

The [wiki](https://github.com/UAMS-Web/UAMSWP-Content-Syndication/wiki) covers what the plugin does, a first news list, every shortcode attribute, the output formats, the hooks, and troubleshooting. Its pages are kept in [`docs/wiki/`](docs/wiki/) and published by the `Publish wiki` workflow; edit them there through a pull request.
